# Docspress WordPress plugins

WordPress plugins maintained as part of Docspress live here, with one subdirectory per plugin.

- [`docspress-blocks/`](docspress-blocks/) provides documentation-focused Gutenberg blocks, starter patterns, the documentation shell the theme's templates compose (navigation, search, table of contents, Page feedback, and `llms.txt`), and **modules** (Mantle-style feature folders under `includes/Modules/` + `src/modules/`). The first module is **Pages List** — an opt-in hierarchical DataViews Pages screen for deep documentation trees.

This directory and the sibling `theme/` directory are repository distributions. They are intentionally excluded from the `docspress` npm package.
